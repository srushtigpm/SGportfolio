## Writing a post

Every post is a Markdown file in `src/content/blog/`. Copy this one, change the title, date and summary at the top, and write underneath. The site picks it up on the next build.

You can use **bold**, *italics*, [links](https://example.com), lists, and quotes:

> The lantern doesn't light the whole mountain. Just the next few steps.

- Headings become chapters.
- Images go in `public/` and are linked like `![alt text](/SGportfolio/image.jpg)`.
- Set `draft: true` at the top to hide a post while you work on it.
